# Documentation

This folder contains supporting documentation for the inverted-pendulum-ees project. It is intended to help readers understand the system architecture, the main components of the testbed, and the ideas behind the benchmarking workflow.

## Overview

inverted-pendulum-ees is a testbed for inverted pendulum systems designed for rapid benchmarking and real-time evaluation of different control architectures and observability mechanisms. The documentation in this folder provides a high-level reference for how the project is organized and what each part contributes.

## Core parts

The project is centered around a few key elements:

- Plant model: the physical dynamics of the inverted pendulum system, including the cart and pendulum behavior.
- Controller: the control strategy used to stabilize the system and track desired behavior.
- Observability mechanisms: methods and components used to estimate or infer system state information.
- Benchmarking and evaluation: tools and experiments used to compare control approaches under repeatable conditions.
- Documentation and notes: design notes, explanations, and reference material that support development and analysis.

## Usage

Use this documentation as a starting point for understanding the repository structure and the role of each major subsystem. Additional notes and implementation details can be added here as the project grows.
